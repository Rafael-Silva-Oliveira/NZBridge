    Latest releases and upcoming features.

    v0.5.1 Current

    • Every attachment is now its own checkbox row: expanding an item shows the main attachment pre-ticked (labeled "Main ·") next to its supplementary PDFs and links — untick the main there if you only want one of the other attachments
    • Hovering a row shows the full attachment filename, so long titles are easy to tell apart; attachment rows display the filename (matching the name NotebookLM gives the source) instead of the Zotero item title
    • Collapsible PDFs / Web URL groups (▾) and drag-to-resize group panes — both remembered between opens
    • "Check notebook" now reliably detects sources you deleted in NotebookLM and clears them for re-upload — including individual attachments of the same paper, and even if you removed every source — even while other sources are still processing. When a check can't read the notebook, it says so instead of implying nothing was deleted, and the result lists each cleared source as a bullet
    • Fixed: ticking the main attachment could upload a different file than the one shown (the exact attachment you tick is now uploaded)
    • Your tick selection is kept across uploads and "Check notebook" re-renders, and even when the popup is closed and reopened
    • ✓ markers now name the exact source in the notebook on hover and explain how to replace it (delete the source in NotebookLM, then Check notebook)

    v0.5.0

    • Choose which attachments to upload: items with several attachments (e.g. a paper plus its supplementary PDF, or a link attachment) now show a ▸ in the item list — expand it and tick the attachments you want. By default the main attachment is synced, exactly like before
    • The default attachment now matches the one Zotero opens when you click the item (previously the first attachment found was used, which could differ)
    • Items with multiple URLs (DOI, publisher page, link attachments) can be expanded to pick a different link than the automatically chosen one
    • Already-uploaded items keep their ✓ but can still be expanded to upload their remaining attachments

    v0.4.4

    • Zotero 10 support: Zotero 10 was released on 17 August 2026 and reported NZBridge as incompatible, so the plugin could not be installed or updated. NZBridge now installs and runs on Zotero 10
    • Zotero 10 also changed how the selected collection is read, which would have broken the "Sync to NotebookLM" and "Import Notes from NotebookLM" right-click menu items. Both work again
    • Still fully compatible with Zotero 7, 8 and 9 — this is the same single plugin, and nothing changes if you are staying on your current version

    v0.4.3

    • Gemini Notebook support: NotebookLM has rebranded to Gemini Notebook at notebook.google.com, which broke tab detection and caused "No NotebookLM tab found" errors and PDFs no longer uploading from Zotero. NZBridge now detects both the new notebook.google.com and the legacy notebooklm.google.com hosts, so sync works during the rollout regardless of which domain your account uses
    • Thanks to b0nl and yt_zhang for reporting the Gemini Notebook domain change that broke sync

    v0.4.2

    • More reliable PDF uploads: a transient miss on the "Upload files" button no longer fails a batch of sources. The click is now retried automatically, so the files that previously needed a manual re-sync go through on the first attempt
    • New tag picker on the To Zotero tab: pick from your existing library/group tags in a searchable list and add them as chips, or type a new tag and create it on the spot (new tags are marked with a "+")

    v0.4.1

    • New "Search by" toggle on the To NotebookLM tab: choose between Zotero collections and Zotero tags
    • Tag-based sync finds all items with a selected tag across the chosen library and uploads them to NotebookLM
    • Tag selections are remembered when you close and reopen the popup, just like collection selections
    • Collections remain the default search mode; tags are an opt-in alternative
    • "Check notebook" and "Reset" work for both collection-based and tag-based syncs

    v0.4.0

    • Uploaded sources now show a green check — items already in the connected notebook are marked and skipped, so you only sync what's new
    • "Already uploaded" is tracked reliably per notebook: PDFs by filename and URLs by their source link, so it survives closing/reopening the popup and isn't fooled by renaming a source in NotebookLM
    • New "Check notebook" button: clears the green check from any source you removed in NotebookLM so it can be re-uploaded (may take a minute — click again and check back)
    • Cancel upload: stop a sync in progress; files already uploaded are kept
    • Pin the popup into a floating, movable window that stays open while you work in NotebookLM
    • The To Zotero tab now defaults its target to the collection you picked for syncing (still changeable)
    • Your selected collection is remembered when you reopen the popup
    • Items are unchecked by default so you pick exactly what to upload; refreshed, more even UI in light and dark mode

    v0.3.3

    • Fix: "Find Text Notes" reliably finds saved text notes again after NotebookLM's Studio redesign. Notes are detected by structure, not timestamps, and never confused with Studio generators (Slide Deck, Mind Map, etc.)
    • Fix: each note now extracts its own content correctly (no more duplicated text) in both the expanded and collapsed layouts, including read-only saved responses
    • Inline citations become readable markers like (20,21); years and other numbers are left untouched
    • Fix: importing URLs after PDFs now works. The "Websites" option in the Add sources dialog is found reliably
    • Found notes are remembered per notebook. Close and reopen the popup without losing them, then re-run to refresh
    • Searchable collection pickers: start typing to filter your Zotero collections
    • Dark mode (default) with a toggle in the top-right, plus faster note extraction

    v0.3.2

    • Fix: connection to Zotero now works on Chrome/Edge 142+ — if the browser blocks it, the popup shows how to enable "Local network access"
    • Fix: requests no longer hang for minutes when the local connection is blocked; they fail fast with clear guidance
    • Faster PDF uploads — files upload in batches and each is verified in NotebookLM before continuing, so syncs are quicker while still ensuring every file lands

    v0.3.1

    • Multilingual NotebookLM support — sync now works on non-English NotebookLM interfaces (Chinese, Japanese, Korean, Spanish, French, German, Portuguese, Italian, Dutch, Indonesian, and more)
    • You no longer need to switch NotebookLM to English before syncing
    • Mappings tab shows a just-synced notebook immediately, even before the Zotero mapping list refreshes

    v0.3.0

    • Group library support — sync items from any Zotero group (private, public-closed, or public-open) to NotebookLM
    • New Library dropdown: pick which library to browse before choosing a collection
    • Mappings tab now shows which library each sync belongs to

    v0.2.1

    • Fix: PDF uploads no longer silently drop files when syncing large collections — all PDFs now upload reliably
    • Up to 3 automatic retries per file with backoff if the upload dialog doesn't respond in time
    • Better error messages — shows exactly which PDFs failed and how many, instead of truncating to 3 errors
    • Note: upload time per file may be slightly longer than v0.2.0 to ensure reliability. Actual time depends on PDF size, your internet connection speed, and NotebookLM's response time

    v0.2.0

    • Selective sync — choose exactly which PDFs and URLs to upload before syncing
    • Real-time progress bar with per-file status and item counter
    • Progress is preserved if the popup is closed and reopened mid-sync
    • Faster PDF uploads — ~3-5s per file (down from ~10-15s)
    • Fixed: PDFs no longer open as new browser tabs instead of uploading

    v0.1.3

    • The 50-source limit is now a warning, not a blocker — Pro plan users can sync collections larger than 50 items

    v0.1.2

    • Fix: correct NotebookLM tab targeting when multiple notebook tabs are open
    • Fix: "Add sources" failures caused by syncing into the wrong tab
    • Fix: file-chooser interception now always cleaned up on error (restores manual uploads)
    • Fix: PDF uploads on macOS and Linux (path separator handling)
    • Fix: clearer errors when Zotero is not running or the plugin is unavailable
    • Fix: popup no longer hangs forever if the background worker is slow
    • Guard: prevents two syncs from running simultaneously on the same tab
    • Backward sync prefers the originally mapped notebook when multiple are open

    v0.1.0

    • Forward sync: upload PDFs and URLs from Zotero to NotebookLM
    • Backward sync: extract text notes from NotebookLM Studio
    • Smart URL selection (prefers open-access over bot-protected links)
    • Auto-naming of new notebooks after Zotero collections
    • Parent document items for Notion/Notero compatibility
    • Custom tags and default tags on imported notes
    • Collapsed/vertical layout support
    • Duplicate detection and overwrite on re-import
